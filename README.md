# 주요일정 취합 도우미

본부 실처에서 받은 다음 날 일정(HWP/HWPX)과 주간 임원일정을 모아 한글 양식의 주요일정 취합본(HWPX)을 만드는 업무 자동화 도구입니다.

## 구성

| 경로 | 내용 |
|---|---|
| `실처일정/scripts/build_schedule.py` | 취합본 생성 (`python -I build_schedule.py YYYY-MM-DD`) |
| `실처일정/scripts/watch_live.py` | 10분 단위 초안 갱신 |
| `실처일정/scripts/*.ps1` | 한글 2020으로 HWP→HWPX 변환, 미리보기 그림 생성 |
| `웹앱/` | 내 PC 전용 현황 화면 (`start_webapp.bat`, 발표용은 `start_demo.bat`) |
| `고객사업본부 주요일정_양식.hwpx` | 취합본 양식 |
| `BRD_*.md`, `PRD_*.md`, `기능_명세서.md`, `웹앱_기획.md` | 요구사항·설계·기능 문서 |

## 필요 환경

- Windows, Python 3 (표준 라이브러리 + Pillow), 한글 2020

## 저장소에 없는 것

실제 업무 데이터(실처 회신 파일, 임원일정, 날짜별 취합본·처리기록)와 개인 업무 맥락 문서는 보안상 올리지 않습니다. 목록은 `.gitignore` 참고.
발표용 임원일정(`발표용/실처일정/주간임원일정/`)은 예시 데이터입니다.
